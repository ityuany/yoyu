# 图表查看约定

- 图表是否提供放大入口，以扩大画布后能否改善数据阅读为准，不因使用了图形就自动提供。单纯把同一比例或单个指标画得更大，不构成放大的理由。

## 类型与判断标准

| 图表类型 | 默认策略 | 判断依据 |
| --- | --- | --- |
| 时间序列折线图、面积图、多序列趋势图 | 提供放大 | 横向画布能展开时间轴、减少标注重叠，便于比较趋势与数据点。 |
| K 线图、密集散点图、热力图 | 按阅读收益提供 | 数据点或网格密集，放大能看清分布、标注和局部差异时提供；稀疏简图不提供。 |
| 柱状图、分组或堆叠柱状图、瀑布图 | 按阅读收益提供 | 类别多、序列多或标签拥挤时提供；少量类别且读数完整时不提供。 |
| 时间轴、甘特图 | 按阅读收益提供 | 时间跨度长、区间或行数多，扩大画布能改善阅读时提供。 |
| 饼图、圆环图、进度环、仪表盘 | 不提供放大 | 通常表达少量占比或单个指标，横屏放大不会增加有用信息。复杂分类优先改用条形图或详情列表。 |
| 迷你趋势图、单值比例条、概览卡片内的简明示意图 | 不提供放大 | 用于快速概览；更多数据通过卡片详情查看。迷你趋势需要展开完整时间序列时，进入详情中的趋势图。 |

- 悠悠分析页的养老保险、住房公积金缺口圆环属于概览图：不提供放大入口或横屏全屏层，保留整卡进入业务详情。
- 新增图表先按上表判断，再检查实际的数据密度、标签可读性及放大后的具体收益；不要机械地只按图表类型决定。

## 支持放大的图表

- 右上角统一提供放大图标，沿用职业回顾的 `arrow.up.left.and.arrow.down.right` 样式，点击区域至少 44 × 44 pt，并提供明确的无障碍名称。
- 点击后打开独立的全屏查看层，以横向布局展示图表，充分利用宽度，清楚呈现坐标、数值与图例；可沿用职业回顾在全屏层内旋转画布的实现，无需改变整个 App 的方向约束。
- 全屏图表必须沿用进入前的时间范围、筛选及当前选择，不得重置为默认范围。普通视图与全屏视图复用同一数据与绘图规则。
- 全屏层隐藏底部标签栏，提供明确的关闭按钮；关闭后恢复原页面，保留筛选及滚动位置。
- 无可绘制数据或数据异常时，放大入口禁用或隐藏，页面说明原因。
- 后续新增或调整图表时遵循本约定；既有图表按任务范围逐步补齐。
- 验收使用系统默认字号，覆盖浅色与深色；支持放大的图表检查打开、横向展示、关闭及范围保留，不支持放大的概览图检查没有放大入口且详情导航正常。
