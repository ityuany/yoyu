# 导航设计原则

后续新增和调整页面时，尽可能遵循以下原则，以页面用途判断，不以二级、三级等层级深度机械决定底部标签栏显隐。

- **浏览时保留**：主页面、列表、普通详情和逐层深入的浏览页面，优先保留底部标签栏，便于识别当前栏目并随时切换。
- **编辑时覆盖**：新增、编辑、关联选择等独立任务，优先使用 sheet 等模态页面覆盖底部标签栏，提供明确的取消和保存／确认入口。选择或输入先保存在页面草稿中；取消不写入业务数据，保存成功后返回，失败保留页面并提示。
- **全屏查看时按需隐藏**：图片、图表等需要沉浸查看的内容可以全屏展示，并提供清晰的关闭或返回方式。
- 以上是项目优先采用的设计策略，不是所有页面的硬性模板。收益测算、筛选等即时交互可以留在浏览页面；不要仅因页面有输入控件就强制改成模态。
- 同类任务尽量采用一致的进入和退出方式。避免为了隐藏标签栏制造重复详情页或额外导航层级；完成任务后回到原来的上下文。
