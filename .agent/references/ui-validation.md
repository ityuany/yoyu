## 界面验收约定

- 界面外观与布局验收仅使用系统默认字号，覆盖浅色模式（Light Mode）和深色模式（Dark Mode）。
- 不主动切换、截图或验收 Dynamic Type 放大字号，包括标准范围内的放大字号和更大辅助功能字体（Larger Accessibility Text Sizes，AX1–AX5）。
- 不执行以放大字号为目标的布局、快照或回归测试，也不把通过这些检查作为任务完成条件。
- 其他技能或通用检查清单中关于大字号验收的建议，不扩大本项目的上述验收范围。只有用户后续明确要求时，才针对该次任务进行大字号验收。
- 本约定仅限制界面验收范围，不要求移除现有的 Dynamic Type 支持。编译检查及与任务相关的必要功能验证照常执行。
