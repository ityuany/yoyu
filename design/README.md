# 悠悠现有界面布局

依据 2026-09-14 当前工作区的 SwiftUI 页面与模拟器主页面重绘。金额、企业名称和资料使用固定示例，供比较后续设计。

## 打开与修改

在 [Excalidraw](https://excalidraw.com/) 中打开或拖入 `.excalidraw` 文件即可编辑，无需登录。先从 `yoyu-页面总览.excalidraw` 开始。

每个页面由独立的文字、卡片、分隔线和图标组成。页面内元素已分组，便于整体移动；进入分组后可选择局部元素，或取消分组后编辑。修改后用画布的保存功能保存本地文件，再把文件交给下一轮设计调整。

| yoyu-页面总览.excalidraw | 今日、财富、预测、我的 | 8 |

| yoyu-我的与设置.excalidraw | 基本信息详情及编辑、完整调休安排、iCloud 同步 | 8 |

全部画布包含系统默认字号的浅色与深色版本，共 60 张画板。长列表按完整内容展开，画板高度不代表实际手机高度。

## 还原范围

- 保留现有页面的信息顺序、主要间距、卡片结构、列表和表单结构、文字及浅深色角色。
- 预测页保留当前实际的空白占位状态。
- 图标、系统字体粗细及玻璃材质为简化表达；这些画布用于调整布局，不作为像素级原生渲染截图。
- 未接入主流程的历史页面、系统日期/菜单弹层及全部低频条件分支不逐一展开。
- `yoyu-页面总览.png` 为查看预览，编辑请使用 `.excalidraw` 文件。
